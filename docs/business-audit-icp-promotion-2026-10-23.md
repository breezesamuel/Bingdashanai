## 2. 客户是谁（双重逆向，不靠猜）

### 2.1 从 APINebula 的证言角色反推
它的 6 条证言覆盖：AI 初创 CTO、独立开发者、产品经理、研究生、技术总监、全栈工程师。
共同点：**技术自决、怕订阅打水漂、要支付宝、要对成本有掌控**。
这告诉我们一件事：**"按量/可停"比"功能多"更能打动技术型买家**——我们的"随时停 + 日限透明"正好对口。

### 2.2 从我们自己的用量反推（信号，而非结论）
| 模块组 | 7 日用量 | 占比 | 说明 |
|--------|---------|------|------|
| 经营驾驶舱（warboard/decision/org/evolve） | 987 | **87%** | 拍板、盯目标、带团队、沉淀复盘 |
| 执行与技能（skill/agent/chatdeep） | 156 | 13.7% | 具体任务执行 |
| 内容生产（studio/game/music） | 44 | **3.9%** | 几乎没被用 |

→ 用一句话定义客户：**"要拍板、要盯进度、要带团队的人"**，不是"要出片的人"。

### 2.3 三类 ICP（理想客户）

**A. 主 ICP — 10~200 人公司的"一号位/操盘手"**（创始人、总经理、业务负责人）
- 规模：10-200 人，已有飞书/钉钉/企微，但没有"决策-目标-复盘"的闭环工具
- 预算：¥99-899/月，**可自决**（不需要走采购流程）
- 痛点：决策靠拍脑袋；季度目标定完没人跟；复盘会开成甩锅会；新人接手上手要两周
- 触发事件：季度目标下发、核心员工离职、一次明显的决策失误、投资人要月度经营数据
- 反对意见：「又一个聊天机器人」「数据放你那我安全吗」「飞书/钉钉够了」
- 成功定义：3 个月内目标达成率可量化提升；失败定义：买了不用（7 天无核心模块使用）

**B. 次 ICP — 乙方专业团队**（咨询 / 代运营 / 财税 / 设计工作室，3-30 人）
- 用 warboard + org + evolve 做**交付标准化**，把方法论变成可复用资产
- 预算：¥269-899/月，**按项目转嫁给甲方**
- 触发事件：接了更大的单、要带新人、客户要求过程透明
- 说服点：不是"AI 帮你写"，是"你的方法论被固化成系统"

**C. 明确排除**
- C 端内容创作者（不需要组织/决策模块，只用 studio，而 studio 用量仅 36/周）
- 学生 / 个人尝鲜者（¥1 体验后不续费，占用免费额度）
- 纯 API 开发者（他们要 token 不要工作台，那是 APINebula 的客户）

## 4. APK 还是 EXE？（基于真实产物，不猜）

| 形态 | 现状 | 建议 | 依据 |
|------|------|------|------|
| **Windows EXE** | **已产出** `BingDashanAI-2026.0.3-win-x64.exe`（88 MB，NSIS） | **主推** | 本地 Node 服务 + 文件系统 + ffmpeg + 24h 调度，桌面是原生产形态 |
| **PWA** | 已具备（manifest / sw.js / 全套图标 / 安装提示） | **辅推（随行）** | 手机看板、审批、临时查看足够；无安装门槛 |
| **Android APK** | 仅 Capacitor 脚手架，**无产物** | **暂不做（延后）** | ① 本地 Node server 不能直接在 Capacitor WebView 跑，需 nodejs-mobile 重架构；② 主 ICP 在 PC 前办公；③ 88MB 资源 + 审核成本 |
| iOS | 无 | 不做 | 同上 + AI 生成内容审核风险 |

**结论**：**EXE 为主、PWA 为辅、APK 只做"只读伴侣"**（看板 + 审批），且**等有 10 个付费客户后再投入**。
判断依据是客户行为：他们需要"在电脑前拍板"，手机端真实需求是"看数和批一下"，不是"生产"。

## 5. 商业评估与修复

### 5.1 定价审计（发现 3 个问题）
1. **档位太多（7 档）**：¥1/99/269/899/199/399/699 → 选择过载。建议收敛为 **3 档**：
   体验 ¥1（7天） / 标准 ¥99（月） / 团队 ¥699（月，5 席位）。
2. **季度折扣偏低**：季度省 9%（月付 ¥99 → 季付 ¥89.7/月），年付省 24%。季度应到 15% 才有引导力。
3. **中英价不同步**：¥99/月 vs $12/月（≈¥86），¥699 vs $89（≈¥640）→ 需明确是"区域定价"还是"汇率错误"。
   > **未擅自改价**：定价是商业决策，需你确认后我再动 `core/subs.js`（有回归测试保护）。

### 5.2 单位经济（诚实版）
- **现在毛利不可计算**：成本台账 0 条（LLM 未开）。任何"毛利率 80%"的说法目前都是估算。
- 可用上限估算：¥99/月，重度用户日耗 8 次深度推理 + 少量 agent，按 deepseek 估算价（¥2/¥8 每百万 token），单用户月成本大概率 **< ¥15**。
- **必须**在开 LLM 后 48 小时内按真实账单校准 `settings.costPrices`，再用 `/v1/usage/margin` 看真实毛利。

### 5.4 本次代码级修复（已上线）

**① 收费墙曾 fail-open（最严重，已修）**
线上 `core/subs.js` 是旧版本：`gatePool()` 缺少 `freeLeft <= 0` 拦截。

同时缺"人工核账 24h 乐观放行"，导致付了钱的客户仍被 402 拦截。
两处修复 9 行，已与本地对齐（md5 一致）、备份后上线，隔离复现验证：
`freeLeft=0 → gatePool allowed:false, wall:true`。
