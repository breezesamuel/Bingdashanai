## 推广文案要点

### 差异化卖点（USP）
1. **本地部署**：数据完全归自己，不上传第三方
2. **无抽成**：支付宝/微信个人码收款，100% 归开发者
3. **11个功能分区**：深度思考/决策/技能/Agent会诊/获客/音视频/游戏/音乐/战情室/组织大脑/进化
4. **24h 自主运营**：autopilot 自动轮询执行
5. **fail-closed 支付**：不确认不开通，不虚假承诺
