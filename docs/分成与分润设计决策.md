## 二、平台抽成：5% vs 10%

### 2.1 竞品真实数据

| 平台 | 定价 | 对营收抽成 | 资料日期 |
|---|---|---|---|
| **Polsia** | $20/月/公司，$19/月 仅托管版 | **收款 3%** + 广告费 20% | 2026-09-17 条款 |
| Polsia（旧） | $49/月 + 20% | 20%（营收+广告费） | 2026-06 条款，已下调 |
| Pancake | $99/月 固定 | **0%** | 2026-09 |
| TryCook | $97/月起 | **0%** | 2026-03 |
| Stedral | €99 / €279 / €599 固定 | **0%** | 2026-06 |
| NanoCorp | $30/月 | 提现时 20% | 2026-09 |

### 2.2 三个关键判断

**① 10% 在当前市场没有位置。** 你想比较的 5%/10% 都高于 Polsia 今天的 3%，而 Polsia 是拿着 $30M 融资、$250M 估值、$2M ARR 的头部玩家——它主动把 20% 砍到 3%，说明 20% 已被市场证明是增长阻力。10% 更是站在 3% 的三倍高位。

**② 抽成的真实问题不是"抽多少"，而是"抽的是什么"。** Polsia 的做法值得抄：**对营收只抽 3%，但对广告预算抽 20%**。逻辑是——
- 平台为每笔营收提供了**托管/运维**（真实成本）→ 抽 3% 合理；
- 广告费是**平台代管的零和买量**，平台加价 20% 等于赚"渠道服务费"；
这样既保住营收端低抽成的口碑，又在真正有服务增值的地方收钱。

**③ "惩罚成功"是抽成模式的头号差评理由。** TryCook 的公开批评很直白：Polsia 抽成随规模上升，"越成功交得越多"。Dealroom 数据显示 Polsia 头部用户月收入约 $50——抽成对小用户伤害最大（$50 × 20% = $10，占了 1/5）。而丙大山当前 KPI 是"半年千万"，早期客户绝对值小，**高抽成会直接劝退第一批种子用户**。

### 2.3 建议方案（阶梯抽成）

```
年营收 < 10 万   → 3%    （冷启动期，几乎不抽，让种子客户活下来）
年营收 10–100 万  → 5%    （进入正轨，回收托管成本）
年营收 > 100 万   → 3%    （规模越大越让利，形成正循环）
外加：代管广告预算  → 20%  （对齐 Polsia，平台代买量收服务费）
```
**理由**：低抽成打价格战（竞品都在 0%），但**用阶梯而不是单一比例**——起步 3% 抢客户，10–100 万区间 5% 覆盖托管成本，冲量后回落 3% 奖励规模。这比"5% 或 10% 二选一"更符合当前竞争格局。

## 三、合伙人分润：为什么不能用宝塔方阵

### 3.1 法律红线（不可协商）

《禁止传销条例》（2005 施行，至今有效）：

- **第二条**：以发展的**人员数量或销售业绩**为依据计算和给付报酬 → 传销
- **第七条（三）**：形成**上下线关系**，并以**下线的销售业绩**为依据给付上线报酬 → 传销
- **第二十四条**：没收违法所得 + 罚款；**构成犯罪追究刑事责任**

2026-05-29《修订征求意见稿》（尚未生效，但释放明确收紧信号）：
- 罚款由定额改为**违法所得 3 倍**，违法所得无法计算时 **100 万–500 万**
- 新增**信用惩戒**：直接责任人 3 年内不得任法定代表人/董事/高管
- 新增**处罚到人**、资金监控、**网络传销**专章

刑事门槛（2013 两高公安部意见）：内部参与 30 人以上且层级 3 级以上 → 组织领导传销活动罪。

### 3.2 合法与违法的唯一分界线

这是本次调研最有价值的一条（来源：国家工商总局直销监管局 2010 年答复 + 业内法律分析）：

| | 合法代理 | 团队计酬传销 |
|---|---|---|
| 佣金来源 | 下级**从我这进货**赚差价 | 下级**销售业绩**，哪怕**不从我进货** |
| 关键 | 存在**真实进出货/服务交易关系** | **仅凭推荐关系**就返利 |
| 结果 | 下级可绕开我直接拿货 → 我自动失去该佣金 | 下级永远是"我的人"，业绩再大我也抽成 |

**一句话**：佣金必须锚定"**真实发生的交易**"，不能锚定"**谁推荐的**"。

### 3.3 建议方案：单层直推 + 真实交付分润

```
                     ┌─────────────────────────┐
   客户成交 ────────→ │  丙大山平台（抽成 3–5%） │ ──→ 客户收到服务
                     └───────────┬─────────────┘
                                 │  扣除平台抽成后的净收入
                                 ↓
                     ┌─────────────────────────┐
                     │  合伙人（真实交付方）   │ ──→ 合伙人收到分润
                     └─────────────────────────┘
                                 ↑
                     仅此一层。无上线、无下线、无层级奖金。
```

**链路上必须真实发生的四件事**（每一步都要留痕，这是合规的护身符）：

1. **合伙人必须真的交付**：为该客户提供了什么服务（决策报告/陪跑/工具使用/复盘），有工时、有交付物、有验收记录。
2. **佣金锚定成交额**：按"该合伙人**亲自促成的这一单**"的净收入计提，**不看这个客户后来又带来多少人**。
3. **不设入门费**：合伙人免费成为，不收加盟费/资格费（收即触犯第七条二）。
4. **单层封顶**：只到直接成交这一层。客户再推荐新客户，新客户归新客户的直接服务人，与原合伙人无关。

### 3.4 明确禁止（写进产品逻辑，不只是口头约定）

- ❌ 以"下线人数"计酬（拉人头）
- ❌ 以"下线团队业绩"计酬（团队计酬）
- ❌ 收入门费/加盟费取得资格
- ❌ 任何形式的"永久下线的永久收益"
- ❌ 层级奖金（越上层抽越多）
