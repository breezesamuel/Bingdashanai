手机上装（免应用商店）

用手机浏览器打开本页面，按下面步骤把网页装成 App。这是 iOS / 鸿蒙目前唯一不需要应用商店的安装方式。

iPhone / iPad（iOS）

iOS 原生包需 Mac + Xcode + Apple 开发者账号构建，现阶段请用 PWA。
  1. 用 Safari 打开本站（不要用微信内置浏览器）。
  2. 点底部 分享 → 添加到主屏幕。
  3. 主屏出现图标，点开即为全屏 App。

Android

有 APK 时优先用 APK；没有也能用 PWA 安装。
  1. 用 Chrome / 华为浏览器 打开本站。
  2. 菜单 → 安装应用 / 添加到主屏幕。
  3. 之后从桌面图标启动。

鸿蒙（HarmonyOS）

原生 HAP 需 DevEco Studio 构建，现阶段请用 PWA。
  1. 用 华为浏览器 打开本站。
  2. 菜单 → 添加到桌面。
  3. 从桌面图标启动。

安装之后怎么开始用

  1. 打开 App：首次运行会在本机起服务，界面在 http://127.0.0.1:3721（仅本机可访问）。
  2. 先用免费额度：未订阅也有免费次数，用出价值再决定付费。
  3. 选套餐并付款：在 套餐页 选择；运营方确认到账后开通（不承诺“自助秒开”）。
  4. 激活：下载版在 App 的 激活页 粘贴授权码，本机全部付费功能开通。
关于安装时的安全提示（如实说明）：当前安装包没有代码签名证书。Windows 可能弹 SmartScreen（更多信息 → 仍要运行）；macOS 首次打开需右键 → 打开。这不是病毒，是本项目尚未购买签名证书。介意的话请先核对下方 SHA256。

核对下载文件（可选）

下载后本地算一次哈希，与页面上的值比对，可确认文件没被替换。

Windows（PowerShell）

Get-FileHash .\BingDashanAI-Setup.exe -Algorithm SHA256

macOS / Linux

shasum -a 256 BingDashanAI-*.dmg
